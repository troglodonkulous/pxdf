# Same 71 clips, same machine and Electron build as
# `decoder-load-2026-09-19-job-library.txt`. Two things changed between that
# file and this one, and they have to be read together.
#
# 1. `PlayScreen`'s two fan-outs now run through `app/src/player/taskPool.ts`,
#    four wide apiece.
# 2. The probe gained a fourth arm — the `census:` line below — because
#    without it this run could not tell the fix from its own absence.
#
# ## Why the instrument moved, which is not a thing to do lightly
#
# The first bounded run of the *unmodified* probe printed 71/71 thumbnails and
# exited 0. So did a run of it against a build with the concurrency limit
# deliberately taken back out. The mutation-check came back green, and that is
# a fact about the probe.
#
# The outcome arms count a race. `captureThumbnail` carries a 5 s deadline that
# starts when the fan-out creates it, and whether a queued decoder beats that
# deadline depends on the OS page cache. The pre-fix file's 6/71 was a cold
# library; four later runs of unbounded builds in this session read 43, 43, 63
# and 71 out of 71 once the files were all cached, against 71, 71, 71 for three
# bounded runs. Nothing available here can make the library cold again.
#
# So the probe was given a reading that does not depend on timing at all: the
# high-water mark of the app's own decoder census, read back out of the
# heartbeat. It counts decoders held open, not how fast they finished. It is
# graded without naming any limit — `peak` must come in under the number of
# cues added, which no per-cue fan-out can manage and any real bound clears
# easily — and it is graded only at 32 cues or more, where 2N is far enough
# above N for the check to mean something.
#
# ## The mutation-check, re-run against the instrument that can see it
#
#   limit in place    census: peak=8    ... exit 0     <- this file
#   limit removed     census: peak=142  ... exit 1
#     - the window held 142 decoders open at once for 71 cues — that is a
#       fan-out with no limit on it, whatever the thumbnail count above says
#
# The removed-limit run printed `71/71 cue rows show a thumbnail` on its way to
# failing. That is the whole case for arm 4 on one line.
#
# `opened` is 143 in both, so the fan-out still does all of its work. It just
# stops doing all of it at once.
